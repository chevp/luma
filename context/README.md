# context/ — chevp-ai-framework artifacts

This directory holds the persistent artifacts of the chevp-ai-framework lifecycle for `chi`. The framework itself is loaded from <https://chevp.github.io/chevp-ai-framework/chevp-ai-framework.md> via the `@url` block at the top of [../CLAUDE.md](../CLAUDE.md).

| Folder | Purpose |
|--------|---------|
| [architecture/](architecture/) | System design artifacts (non-ADR) |
| [adr/](adr/) | Architecture Decision Records — `ADR-NNN-<title>.md` |
| [guidelines/](guidelines/) | Project-specific tightening of framework rules |
| [plans/](plans/) | CTX / EXP / PRD plans, organised by lifecycle status |
| [specs/](specs/) | Feature specifications produced during Exploration |
